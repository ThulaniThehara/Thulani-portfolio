## The Problem

Generic conversational AI interfaces lack domain-specific musical structure knowledge: they ignore poetic meters, fail to maintain consistent rhyme schemes, and produce generic verses without emotional nuance or tonal constraints.

## Goals

- **Streaming Latency**: Deliver instantaneous token streaming to maintain creative momentum.
- **Rhyme & Meter Constraints**: Guarantee phonetic rhyme matching via custom grammar and syllable constraints.
- **Contextual In-Filling**: Allow users to highlight specific bars or stanzas and prompt targeted variations.

## Implementation

### 1. Low-Latency Server-Sent Events (SSE)
Lyrical completions are streamed chunk-by-chunk using asynchronous generators in FastAPI, providing writers with zero perceptible wait time:

```python
@app.post("/api/generate-stanzas")
async def generate_stanzas(payload: PromptRequest):
    async def event_generator():
        stream = await openai_client.chat.completions.create(
            model="gpt-4-turbo",
            messages=build_lyric_prompt(payload),
            stream=True,
        )
        async for chunk in stream:
            token = chunk.choices[0].delta.content or ""
            yield f"data: {json.dumps({'token': token})}\n\n"

    return StreamingResponse(event_generator(), media_type="text/event-stream")
```
